# ADR-008: Pinned MCP SDK and negotiated protocol

- Status: accepted
- Date: 2026-10-05
- Scope: approved M0–M2 implementation plan; later profiles remain capability-gated.

## Context

Agent integrations need a real client/server handshake and schemas shared with other surfaces rather than bespoke tool-shaped success stubs.

## Decision

Pin @modelcontextprotocol/sdk 1.32.1. Use low-level Server with StdioServerTransport or StreamableHTTPServerTransport. SDK latest protocol is 2025-11-25; supported versions also include 2025-06-18 and 2025-03-26. Negotiate, record the actual version in capabilities, and test with the SDK Client. Tools/resources reuse contracts/application authorization; enforce roots, scopes, progress/cancellation and paginated evidence.

## Consequences

stdio stdout is exclusively JSON-RPC. HTTP mounts on authenticated loopback API with capability bearer token and Origin allowlist; no implicit admin role. Secret values never enter free tool arguments. M3 healing/compare tools return isError plus CAPABILITY_UNAVAILABLE with milestone. MCP-001–004, SEC-004/026, D9.

The stdio command accepts `TESTMASTER_TOKEN` (or `TESTMASTER_MCP_TOKEN`) or a private
`--token-file` (default `~/.local/share/testmaster/server.token` created by `server start`). A
dedicated file for an agent is minted with `testmaster token issue --token-file PATH` (default
scopes R,W,X, no admin; local profile only: server-profile tokens come from `/v1/tokens` or the
portal). `mcp serve` itself authenticates the hashed token record and passes its identity/scopes to
services; it does not issue tokens or inherit the default principal. Configured roots and
client-provided file roots are intersected, including realpath confinement. HTTP is mounted at
`/mcp` on the loopback server.

`testmaster_run_tests` returns the durable batch ID as `jobId`; repeat admission with the same
`idempotencyKey`, or reconnect with that `jobId`, to retrieve the same member Runs. A persistent
worker survives the MCP process. Without one, the MCP process owns an ephemeral supervisor and
drains its work after transport disconnect. Explicit request cancellation requests cancellation;
transport closure only detaches waiting. Optional waits emit negotiated progress notifications.
Evidence summaries expose signed cursors and resource links. Artifact and report resources carry
the real `mimeType`: textual types are `text` contents (pages end on UTF-8 character boundaries)
so agents can read them, binary types are `blob`; `_meta` carries `testmaster:next`,
`testmaster:offset` and `testmaster:sizeBytes`. `testmaster://projects/{projectId}/features` maps
feature stable keys to ids (the analyze_code receipt is bounded and only lists the first 100).
Restricted raw artifacts are not exposed. An unknown or missing resource is JSON-RPC `-32002`, a
malformed URI `-32602`.

A wait that reaches its deadline is `UPSTREAM_TIMEOUT` with `waitTimeout`, `runsContinue`, `runIds`
and (for `run_tests`) `jobId`: the runs keep going, and the receipt is rebuilt from live runs on
every read. `bootstrap` is idempotent per approved root (the root's `testmaster.config.json`
project id, else a stored mapping) and never writes files or contacts its target. Every advertised
output schema carries its own `$id` so a client can compile them all in one validator. Annotations
separate read-only tools, additive tools (create records, `destructiveHint: false`) and
destructive ones (execution, cancellation, approval, review). A normalization result above 32 KiB
is announced with a `resource_link` on protocol 2025-06-18 or later; `structuredContent` stays
complete. When the client closes stdin, `mcp serve` answers the calls in flight and exits 0.

Acceptance evidence: `apps/mcp/src/mcp.test.ts`, `apps/mcp/src/surface.test.ts`,
`apps/mcp/src/lists.test.ts`, `apps/mcp/src/authoring.test.ts`, `apps/mcp/src/cancellation.test.ts`,
`validation/journeys/j-mcp.docker.test.ts`, and `validation/results/mcp-001-004.json`.
Vitest inlines the SDK/eventsource dependencies because the workspace `source` resolution
condition would otherwise select unsupported raw dependency TypeScript under Node.
