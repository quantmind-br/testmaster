# ADR-008: Pinned MCP SDK and negotiated protocol

- Status: accepted
- Date: 2026-10-05
- Scope: approved M0–M2 implementation plan; later profiles remain capability-gated.

## Context

Agent integrations need a real client/server handshake and schemas shared with other surfaces rather than bespoke tool-shaped success stubs.

## Decision

Pin @modelcontextprotocol/sdk 1.32.1. Use low-level Server with StdioServerTransport or StreamableHTTPServerTransport. SDK latest protocol is 2025-11-25; supported versions also include 2025-06-18 and 2025-03-26. Negotiate, record the actual version in capabilities, and test with the SDK Client. Tools/resources reuse contracts/application authorization; enforce roots, scopes, progress/cancellation and paginated evidence.

## Consequences

stdio stdout is exclusively JSON-RPC. HTTP mounts on authenticated loopback API with capability bearer token and Origin allowlist; no implicit admin role. Secret values never enter free tool arguments. M3 healing/compare tools return isError plus CAPABILITY_UNAVAILABLE with milestone. MCP-001–004, SEC-004/026, D9.

The stdio command accepts `TESTMASTER_TOKEN` (or `TESTMASTER_MCP_TOKEN`) or a private
`--token-file` (default `~/.local/share/testmaster/server.token` created by `server start`).
It authenticates the hashed token record and passes its identity/scopes to services; it does not
issue tokens or inherit the default principal. Configured roots and client-provided file roots
are intersected, including realpath confinement. HTTP is mounted at `/mcp` on the loopback server.

`testmaster_run_tests` returns the durable batch ID as `jobId`; repeat admission with the same
`idempotencyKey`, or reconnect with that `jobId`, to retrieve the same member Runs. A persistent
worker survives the MCP process. Without one, the MCP process owns an ephemeral supervisor and
drains its work after transport disconnect. Explicit request cancellation requests cancellation;
transport closure only detaches waiting. Optional waits emit negotiated progress notifications.
Evidence summaries expose signed cursors and resource links; artifact and JSON report resources
return bounded base64 pages with an explicit next link. Restricted raw artifacts are not exposed.

Acceptance evidence: `apps/mcp/src/mcp.test.ts`, `apps/mcp/src/cancellation.test.ts`,
`validation/journeys/j-mcp.docker.test.ts`, and `validation/results/mcp-001-004.json`.
Vitest inlines the SDK/eventsource dependencies because the workspace `source` resolution
condition would otherwise select unsupported raw dependency TypeScript under Node.
